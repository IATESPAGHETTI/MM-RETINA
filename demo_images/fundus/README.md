# Demo fundus images

Where appropriately licensed/public fundus photographs for the live demo's
"Select Demo" option should go.

The one currently wired into the website is a real, unmodified GAMMA
dataset sample (training sample 0001, CC BY-NC-ND — see
`../../dataset/README.md` for the full license/citation). It is served
from `../../website/public/demo/fundus/` (Next.js only serves static
assets from `website/public/`, so the actual file lives there rather than
in this folder — this folder documents provenance and is where you'd drop
additional demo images before copying them over).

Do not add real patient images from any source you don't have explicit
rights to redistribute. Do not download images from a general web search
and present them as GAMMA/research samples.
