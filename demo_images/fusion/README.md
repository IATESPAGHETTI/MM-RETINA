# Demo fusion pair

For the "Fusion" analysis mode, the demo needs one matched fundus + OCT
pair from the *same eye and examination* — pairing an arbitrary fundus
photo with an unrelated OCT scan would misrepresent what the fusion model
actually does.

The pair currently wired into the website is GAMMA training sample 0001's
real fundus photograph and one of its real OCT B-scans (see `../fundus/README.md`
and `../oct/README.md`) — a genuine matched pair, not two unrelated images.

If you add more demo pairs, keep them matched (same GAMMA sample id for
both files) and note the sample id here.
